MASJIDUL ASTRA CHILD - complete portfolio theme (v2.0)
=====================================================
Child theme of Astra (Template: astra). Astra must stay installed.
Nothing is activated automatically: install, then use Live Preview first.

INSTALL
Appearance > Themes > Add New > Upload Theme > masjidul-astra-child-complete.zip
(If you uploaded the older "Masjidul Portfolio" theme, you can leave it; this is a separate theme.)
Click "Live Preview" before activating.

WHAT CHANGED IN v2
- Header: compact text name + small mark. The Site Identity logo image is OFF by default
  (Customize > Portfolio Settings > Header and behavior). If turned on it is capped at 34px high.
- One navigation list (Home, About, Education, Research, Publications, Projects, Skills, Gallery,
  Achievements, Contact) used in header and footer. Works from inner pages too.
- Old Astra starter pages (About, Services, Portfolio, Contact) redirect to the matching home section
  (they are not deleted; can be turned off in the same Customizer section).
- Gallery: six distinct original illustrations, each used once. Add real photos in
  Customize > Portfolio Settings > Gallery: your real photos (shown uncropped, duplicates skipped).
- Portrait appears only in the hero.

CONTACT FORM
Sends with wp_mail() to the email in Portfolio Settings. For reliable delivery install an SMTP plugin
(e.g. WP Mail SMTP). Delivery cannot be guaranteed by the theme alone.

EDIT TEXT: Theme File Editor > inc/data.php
